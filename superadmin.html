Ajouter un super-admin
Pour des raisons de sécurité, la création d'un compte super-admin se fait dans la Firebase Console, pas ici.
  1. Ouvre Firebase Console → Authentication → Users
  2. Clique Add user, saisis email + mot de passe fort (16+ caractères)
  3. Reviens ici, connecte-toi avec ce compte au moins une fois — il apparaîtra automatiquement dans la liste ci-dessous
  4. Optionnel : ajoute manuellement à platform/superAdmins/<uid> les métadonnées (rôle, permissions)
⚠ N'active PAS l'auto-inscription publique dans Firebase Auth — sinon n'importe qui peut créer un compte super-admin.
